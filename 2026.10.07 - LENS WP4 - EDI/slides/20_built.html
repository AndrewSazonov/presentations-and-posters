The core is Qt-free and Python-free (ADR-0002). The Python library goes through a thin nanobind module with no logic in it; the desktop and web apps share one Qt/QObject adapter, the web build being that same adapter compiled to WebAssembly with Emscripten; the command line links the C++ core with nothing in between. Sharing the core is intended to keep the results consistent. The browser build still needs to be demonstrated and tested.

What it stands on

The core is Qt-free and Python-free by design (ADR-0002), and the larger dependencies are optional: OpenMP and SLEEF are both build options that default ON for native builds and are simply absent on Emscripten, where the engine falls back to the serial, scalar path. CI gates that fallback — the CRYSTA_SLEEF=OFF scalar build must be byte-identical to the vectorised one, and the same for thread counts. Current limitation: nothing has actually been compiled to WebAssembly yet. crysta has no Emscripten job and edi's app-wasm CI job is still a placeholder, so this is a design that has been kept ready rather than a build that has been demonstrated. SIMD128 for WASM is a listed future lever, not done. Every one of these is free software, and none of them was written for this project.

About eight weeks of development

Bars from the diffraction-lib features page against the crysta feature catalogue, 3 September 2026, with six of them set by the owner’s own reading rather than a feature count: EasyDiffraction at 95 % of calculation modes and of instrument & corrections, 80 % of background/cutoff/texture, 90 % of minimisers, 80 % of fit strategies; crysta at 90 % of EasyDiffraction for structure model and for calculation modes, and crysta at 1 of the 7 single-crystal features (14.3 %), that one being the structure-factor calculation it already does. The background/texture and Le Bail/pair-distribution rows come from one line in that comparison (7 features, EasyDiffraction 6, crysta 2) split here 4 + 3; crysta’s two are the peak-window cutoff and the fitted background, both in the first row, and the one EasyDiffraction lacks is taken to be Le Bail extraction. The totals are unchanged. What is missing is named and planned, not undiscovered. First commit 25 June 2026.
