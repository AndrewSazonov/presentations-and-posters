Each library brings what it does best — written and validated by its own experts

Instead of a new engine, the first route was to rely on what already exists. Out of the field we picked libraries, not programs, and each for what it does that the others do not: CrysFML for symmetry and magnetic structures, CrysPy for polarised neutrons and site susceptibility (needed for MAGIC), PDFfit2 for the pair distribution function. The physics stays with the people who wrote and validated it.

Same project, same objects — whichever way you work

Moving from the application to a terminal to a notebook is not a change of mental model, only of how much you type. The command line is not a separate tool: python -m easydiffraction PROJECT fit refines the very project directory the application saved and writes the results back into it.

Other techniques, and beyond model refinement

Shared: the workflow bar, the screen zones, the parameter table, the run button. Specific: the plot, the model, the names. EasyReflectometry fits a layer model the way EasyDiffraction fits a structure; EasyTexture, built at the University of Göttingen, uses the same interface for a different stage altogether: reducing raw detector data before any model is fitted.
