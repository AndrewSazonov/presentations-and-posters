What the ESS instruments will ask of the analysis: large series, up to a thousand datasets of a hundred patterns each; multidimensional data and very large parameter spaces; and automation, where a bad dataset must not stop the run. The approach of the first half works, but wrappers around several libraries and numerical derivatives are not fast.

A pilot project

Can AI-supported development build a fast crystallographic library?

So we started a pilot project to test the limits: a new crystallographic calculation and refinement library, in C++ for speed, with AI writing the code and a human owning the requirements, the references and the verdict on what is correct. The existing libraries stay essential: every result is checked against them.

crysta
C++ → Python

A fourth calculation engine, built in-house.

crysta is a C++ crystallographic calculation and refinement engine with Python bindings: Eigen for the linear algebra, nanobind for the bindings, CMake to build it. It does not replace the picture from before; it slots into it, as one more calculation engine under the same EasyDiffraction interface.
