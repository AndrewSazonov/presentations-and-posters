Gaps for the ESS instruments, and a steep start for new users.

First what is missing: site susceptibility, needed for MAGIC, exists only in CrysPy and CCSL; 2D Rietveld, needed for DREAM, only in a modified GSAS-II. Then the row slides on to what makes a start hard: a busy main window, input files with cryptic labels, extra software to install, a program for one platform only. The science in all of them is excellent; say so. Historical examples motivating the project; the screenshots do not claim the current installation or operating-system support of those other programs.
