Designed to make everyday analysis easier.

Inspired by the old landing page and both posters; current availability checked in new docs. Code BSD 3-Clause; desktop/browser app GPLv3, with dependency licences retained. Desktop and standalone downloads are not yet published, and signing is work in progress. Do not imply installers are already publicly downloadable. PDF reports are application-only.

Sources: https://enhantica.github.io/edi/about/licence/; https://enhantica.github.io/edi/application/desktop/; https://enhantica.github.io/edi/user-guide/analysis-workflow/report/; https://easydiffraction.org/

Current public documentation https://enhantica.github.io/edi/ and application tutorial index. 25 application tutorials includes the built-in-assistant walkthrough. Desktop distribution is not yet code-signed; built-in updater applies to desktop application. Portable projects are shared scientific project files, not identical interface controls.
