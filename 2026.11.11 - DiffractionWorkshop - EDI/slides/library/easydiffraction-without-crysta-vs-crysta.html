Shared reference checklist, audited on 19 October 2026. Green is diffraction-lib master c0654956; blue combines the implemented physics in crysta main 01b8118d and the product workflows in edi main b128de77. crysta main has the same source tree as edi's pinned SDK. The blue side therefore includes engine APIs even where edi has not exposed them yet. Every item's availability and source links are recorded in data/feature-audit.json. Each row is the fraction of that row's explicitly listed features implemented, with equal item weights and the same denominator for both projects. This is not a universal percentage of all crystallography. A working compatible backend/mode qualifies; stored fields do not. Green/blue implemented counts by row: 15/17 vs 17/17, 7/8 vs 6/8, 12/15 vs 15/15, 9/10 vs 6/10, 2/3 vs 0/3, 0/7 vs 0/7, 0/2 vs 0/2, 4/7 vs 0/7, 7/7 vs 5/7, 7/8 vs 1/8, 6/6 vs 6/6. Compared with the old snapshot, crysta gains anisotropic ADPs, CW profiles and corrections, neutron/X-ray scattering, polynomial backgrounds, multi-phase and sequential workflows and constraints. Remaining gaps include double-b2b/Ikeda-Carpenter profiles, automatic backgrounds, PDF, single-crystal workflows, magnetism, polarised neutrons, MCMC and mixed-engine datasets. The eight-profile checklist excludes additional pure CW Gaussian/Lorentzian kernels, which crysta also implements. Descent policies are not separate minimiser algorithms.
