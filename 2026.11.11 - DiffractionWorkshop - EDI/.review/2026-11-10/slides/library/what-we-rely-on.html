Calculations come from the libraries; the interface is ours.

EasyDiffraction as the worked example — the same three layers hold for the other techniques, with different engines in the bottom row. Say that, or the room hears a claim about diffraction only. The order of the clicks is the argument: the bottom row was already there, written and maintained mostly by other people (CrysPy partly by us). The library above it is the one layer we wrote, so a scientist gets the same objects whichever engine does the arithmetic. Everything above that line is where the design effort actually went. The two outlines that follow say what ships where. The EasyDiffraction library is only our part: the Python API and its Python face; the engines are separate packages it uses. The application bundles everything: its GUI, the library and every engine.
