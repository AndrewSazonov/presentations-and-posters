The same project, whichever way you open it.

The claim is continuity: moving from the application to a terminal to a notebook is not a change of mental model, only a change of how much you type. Worth saying that the CLI is not a separate tool — `python -m easydiffraction PROJECT fit` refines the very project directory the GUI saved, and writes the results back into it. Same objects, same order, literally.
