These are six user routes grouped into three interface families. CLI means commands, including python -m edi, without writing Python code. Interface coverage differs: standalone currently fits only; Python-package CLI has more commands. Web has no built-in assistant. This diagram shows shared scientific inputs and engine, not identical controls or availability.
